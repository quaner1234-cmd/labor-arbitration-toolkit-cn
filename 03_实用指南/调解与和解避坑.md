# 调解与和解避坑

> 公司突然态度变好，说「咱们谈谈」。
> 这可能是好消息 —— 也可能是让你放弃权利的最快方式。
> **本文不替你决定要不要和解。只帮你看清每一条在说什么。**

---

## 先记住三句话

1. **你可以说「我考虑一下」，然后带着文件回家慢慢看。**
2. **没有人能强迫你在看不懂的协议上签字。**
3. **口头承诺不算数。一切以书面为准。**

---

## 最危险的一种方案：「先撤诉，后付款」

```
公司：你先把仲裁撤了，我们下个月就把钱打给你。
                    ↓
        你撤了诉 → 公司不付钱
                    ↓
    你已经放弃了这次仲裁程序，
    要重新走一遍，成本和时间都回来了
```

**🔴 这是最高危的结构。**
如果一定要接受，至少要求：
- **先付钱，再撤诉**；
- 或者在协议里写明「付款后 X 日内撤回」，并约定**逾期不付的违约责任**；
- 或者在仲裁委主持下签**调解书**（仲裁调解书具有法律效力，一方不履行可直接申请强制执行）。

**在仲裁委主持下达成调解、制作调解书，通常比私下签协议安全得多。**

---

## 高危措辞扫描表

看到这些词，停下来想一遍：

| 措辞 | 实际意思 | 危险在哪 |
|---|---|---|
| 「本人因**个人原因**申请离职」 | 你是自己走的 | 赔偿金没了，失业金也领不了 |
| 「**双方再无争议**」「无其他纠葛」「放弃一切权利」 | 这事到此为止 | 金额没谈清就签，等于白签 |
| 「**试用期考核不合格**」 | 承认自己不合格 | 如果你不认可，签了就是自认 |
| 「**双方协商一致**解除」 | 是商量着来的 | 如果实际是被单方辞退，会影响失业金认定 |
| 付款**没写金额** | — | 后面扯不清 |
| 付款**没写时间**（「近期」「尽快」） | — | 遥遥无期，你还没违约条款可用 |
| 付款**没写方式**（哪个账户） | — | 同上 |
| 要求你**放弃社保、公积金主张** | — | 注意：社保相关权利的放弃约定效力存疑，但签了会给你制造麻烦 |
| **空白待填**的地方 | — | 🔴🔴 **绝对不要在空白文件上签字** |

## 签字前核对清单

逐条核对，全部清楚再签：

- [ ] **金额**：数字写清楚了吗？币种？**税前还是税后**？
- [ ] **付款时间**：具体到**哪一天**？不能写「尽快」「近期」
- [ ] **付款方式**：银行转账到**哪个账户**？
- [ ] **违约条款**：对方逾期不付怎么办？有没有约定违约金？
- [ ] **离职证明**：怎么出？什么时候出？**写什么内容**？（这一条经常被漏掉）
- [ ] **社保减员原因**：写成什么？谁来改？什么时候改？
- [ ] **失业金配合**：是否写明单位配合办理？
- [ ] **是否要求撤诉**：如果要撤，**先付钱还是先撤诉**？
- [ ] **放弃权利条款**：我要放弃的到底是什么？列出来了吗？
- [ ] **份数**：一式几份？**我能拿到一份原件吗**？
- [ ] **对方签署**：签字了吗？盖章了吗？签字的人有授权吗？
- [ ] **空白处**：有没有空白没填的地方？（有就不签）

## 「N」「N+1」「2N」是什么意思

谈判桌上大家说的黑话：

| 说法 | 含义 | 什么时候出现 |
|---|---|---|
| **N** | 经济补偿 = 工作年限 × 月平均工资 | 合法解除需补偿的情形（协商解除、裁员、到期不续等） |
| **N+1** | 经济补偿 + 1 个月工资（**代通知金**） | 公司属于《劳动合同法》第四十条情形但未提前 30 天通知的（请核对原文） |
| **2N** | 违法解除赔偿金 = 经济补偿 × 2 | **公司违法解除**时你主张的金额 |

**谈判中的常见过程：** 你主张 2N → 公司说只给 N → 中间落到 N+1。
**谈不谈、接受不接受，完全由你自己决定。**
AI 和本文都不替你做这个决定，只帮你看清楚每个数字对应什么。

## 一个真实的谈判陷阱

有这样一个真实场景（已脱敏）：

> 公司拿出**三份文件**让签字，其中一份是《延长试用期通知》。
> 劳动者说：「我三个月试用期已经过了，凭什么再签延长试用期的文件？」
> 劳动者提议改成：「以后双方互不追究」的写法。
> 调解方说去和公司确认。

**这里的问题在哪？**
- 签了《延长试用期通知》，等于**承认公司有权延长试用期**——
  这会直接削弱你「第二次试用期违法」的主张；
- 就算换成「互不追究」，也要注意**金额、时间、失业金配合**有没有写进去；
- 「互不追究」听起来温和，但如果你还有未结提成、未休年假，
  签了就都要不回来了。

**教训：不要只看「要不要签字」，要看「签的字承认了什么事实」。**

## 三种常见的施压话术，和怎么回应

| 公司说 | 你可以说 |
|---|---|
| 「今天不签就没有了」 | 「我需要考虑一下，明天答复您。」（**没有人能强迫你当场签字**） |
| 「签了这个才好办失业金」 | 「办失业金需要的是非本人意愿中断就业，这个写个人原因反而办不了。」 |
| 「不签就不给你离职证明」 | 「出具解除证明是单位的法定义务（《劳动合同法》第五十条，请核对原文）。」 |
| 「我们律师说你赢不了」 | 「我了解了。我仍然按程序走。」（**不需要和对方辩论法律**） |
| 「签了大家都不难堪」 | 「我理解。我需要看一下条款。」 |

## 在仲裁委主持下调解，通常更安全

- 仲裁庭在开庭时通常会问双方是否愿意调解；
- 达成调解后制作的**仲裁调解书**，具有法律效力；
- **一方不履行的，另一方可以直接向人民法院申请强制执行**。

相比之下，私下签的和解协议如果不履行，你还得走一遍诉讼。
所以：**能走仲裁调解书，就别只签私下协议。**

---

## 拿不准的时候

- 打 **12348**（公共法律服务热线），免费咨询；
- 到当地**法律援助中心**，经济困难可申请法律援助；
- 或者用 [`../02_AI引导工作流/07_随用_看一份文件.md`](../02_AI引导工作流/07_随用_看一份文件.md)
  把协议逐条拆开看一遍。

**在弄清楚之前，你可以不签字。**
