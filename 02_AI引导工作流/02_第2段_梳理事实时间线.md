# 第 2 段：梳理事实时间线

> **用法**：接着第 1 段的对话继续。
> **如果要新开对话**：请把 [`00_规则兜底块`](00_规则兜底块_新开对话时必粘.md)、
> 第 1 段给你的**案件摘要卡片**、以及下面这段提示词，**三样一起粘**。
> （只粘小结不够 —— AI 会不知道要区分【事实】/【推断】/【待核实】。）
> 复制下面框里**全部内容**发送。
>
> ⚠️ **如果你新开了对话**：请把 [`00_规则兜底块`](00_规则兜底块_新开对话时必粘.md)
> 和下面这段提示词**一起**粘贴，否则 AI 不知道要区分【事实】/【推断】/【待核实】。

---

````text
现在帮我把我的经历整理成一条事实时间线。

【输出格式要求】
用 Markdown 表格，四列：

| 日期 | 发生了什么 | 我有什么材料能证明 | 状态 |
|------|-----------|------------------|------|
|      |           |                  | 事实 / 推断 / 待核实 |

【规则】
1. 「状态」列只能填这三个词之一：
   - 事实：我明确说了，且有材料能证明
   - 推断：根据事实推测出来的，必须在「发生了什么」里写明推测理由
   - 待核实：我不能确定，或者材料还没拿到
2. 「我有什么材料能证明」这一列，只写你确实从我这里听到的材料。
   我没提过的材料，一律写「无」或「待补」，**不许假设我有**。
3. 日期写不精确的就写「约 X 月」「X 月前后」，不要编具体日期。
4. 按日期从早到晚排序。

【整理完以后，额外做两件事】
第一件：列出**矛盾点**。公司不同文件、不同说法之间对不上的地方，
单独列一个小表格，写清楚「谁说的 / 说了什么 / 和什么矛盾」。
（这一点很有用：公司说法前后不一致，是庭审中的有力材料。）

第二件：列出**空白点**。你认为应该有、但我没提到的材料或事实，
列成「待补充清单」，每一项写清楚：
- 缺什么
- 这个材料大概能从哪里拿到（比如：银行流水去银行打印、社保记录去社保经办机构或当地政务 APP）
- 谁手里可能有（我 / 公司 / 银行 / 社保机构 / 仲裁委）

【最后】
告诉我下一步应该复制第 3 段提示词（清点证据）。
【这一段的最后，帮我生成一张「案件摘要卡片」】
我要把它保存下来，下次开新对话时接着用，不用再回答一遍。
按下面格式填，我不知道的写「待核实」，不要留空、不要替我编：

【案件摘要卡片 v2】
一、我是谁、告谁：城市 / 公司全称 / 岗位 / 入职日期 / 解除日期 / 月工资（合同与实际分开）
二、发生了什么：按时间列，每条后面写「有材料：XX」或「有材料：无」
三、公司给的解除理由 + 公司给了什么书面文件 + 文件之间有无矛盾
四、我手上的材料：逐项写「有/无」
五、我还缺什么：缺什么 / 去哪拿 / 谁手里有
六、我想主张什么：逐项写「要 / 不要 / 还没决定」（不许替我填）
七、【事实】/【推断】（写明依据）/【待核实】清单
八、下一步该走第【 】段

【最后提醒我三件事】
1. 把这张卡片复制保存到手机备忘录或微信「文件传输助手」。
2. 下次开新对话时，把「卡片 + 规则兜底块 + 下一段提示词」一起发给 AI，
   就能接着走，不用重新回答。
3. 卡片里不要写身份证号和银行卡号。

````

---

## 这段跑完你应该拿到

- 一张**事实时间线表**（事实/推断/待核实分得清清楚楚）
- 一张**矛盾点表**（公司说法对不上的地方）
- 一份**待补充清单**（缺什么、去哪拿、谁手里有）

## 为什么时间线这么重要

仲裁申请书里「事实与理由」那一段，本质上就是这条时间线。
时间线理清了，申请书就写了一半。
而且**矛盾点表**往往是这类案子最有力的部分：公司自己出的三份文件互相打架，
不需要你论证，摆出来就行。
