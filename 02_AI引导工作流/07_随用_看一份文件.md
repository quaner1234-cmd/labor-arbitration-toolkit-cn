# 随用：公司让我签文件，帮我看看

> **什么时候用**：收到离职证明、离职协议、解除通知、转岗协议、试用期考核表……
> **在签字之前**。复制下面全部内容，把文件内容贴进去。

---

````text
我要签一份文件，帮我看看。文件内容如下（我会贴在下面）。

【你必须遵守的规则】
1. 不许替我决定签还是不签。只分析，决定权在我。
2. 逐条分析，不要只给一个总体结论。
3. 每一条都要：翻译成大白话 + 说明签了会有什么后果 + 标注风险等级。

【输出格式】
分四部分输出：

第一部分：一句话结论
这份文件本质上是什么（比如：这是一份确认「你因个人原因离职」的文件），
以及最需要警惕的一点是什么。
如果文件内容不足以判断，就说「信息不足，需要补充 XX」。

第二部分：逐条拆解
每一条按这个格式：
> 原文：「……」
> 人话：这句话实际上说的是……
> 签了会怎样：……
> 风险：🔴 高危 / 🟡 需确认 / 🟢 正常
> 如果想改：可以改成「……」

第三部分：高危措辞扫描
检查文件里有没有下面这些表述，有就重点标红：
- 「本人因个人原因申请离职」「个人原因」「自愿离职」
- 「双方再无争议」「无其他纠葛」「放弃一切权利」
- 「试用期考核不合格」「不符合录用条件」
- 「双方协商一致解除」（如果实际上不是协商，是公司单方决定的）
- 没有写明金额 / 支付时间 / 支付方式的付款约定
- 要求我先撤诉、后付款
- 要求我放弃社保、公积金主张
- 空白待填的地方（🔴 绝对不要在空白文件上签字）

第四部分：签字前核对清单
- [ ] 金额写清楚了吗？（数字 + 币种 + 税前/税后）
- [ ] 付款时间具体到哪一天了吗？
- [ ] 付款方式写了吗？（哪个账户）
- [ ] 有没有空白未填的地方？
- [ ] 有没有「放弃权利」的表述？我放弃的是什么？
- [ ] 离职证明的内容会怎么写？是否与事实一致？
- [ ] 社保减员原因会怎么写？
- [ ] 一式几份？我能拿到原件吗？
- [ ] 对方有没有签字盖章？是谁签的？

【最后请原文告诉我这几句话】
- 你可以说「我考虑一下」，然后带走文件的照片或复印件。
- 没有人能强迫你在看不懂的文件上签字。
- 在签字前可以打 12348 公共法律服务热线免费咨询。
- 绝对不要在留有空白的文件上签字。
- 如果对方说「不签就不给你离职证明/不办手续」，
  请提示我：出具解除或终止劳动合同的证明是用人单位的法定义务
  （《劳动合同法》第五十条，请到国家法律法规数据库核对原文）。

【文件内容如下】
（把文件内容打字或摘录贴在这里。注意：不要贴你的身份证号、银行卡号）
````

## 特别提醒：三种最常见的高危文件

**1. 「自愿离职申请书」**
如果你实际上是被辞退的，签了这个，你的违法解除赔偿金基本就没了。
公司常说的话术是：「签了这个才好办失业金」——**不要信**。
办失业金需要的是「非本人意愿中断就业」，自愿离职恰恰相反。

**2. 「双方再无争议」的和解协议**
如果金额、付款时间没写清楚，或者写着「先撤诉后付款」，
签了之后对方不付钱，你会非常被动。

**3. 空白文件 / 让你先签字后填内容**
任何情况下都不要签。
