# 劳动仲裁自助工具箱

> 给没有法律背景、也没有律师的普通劳动者。
> **不用装软件、不用懂 AI、不用花钱。** 有一部手机和一个 AI 聊天窗口就能开始。

被辞退了、被调岗降薪了、工资被拖欠了，不知道该怎么办？
这个项目帮你在**申请劳动仲裁之前**，把事实、证据、请求、文书整理清楚。

---

## 你现在该做什么（3 分钟）

**如果今天/昨天刚被通知辞退，先做这 4 件事：不要签、要留存、要拿到、要计时。**

1. **不要急着签任何文件。** 尤其是写有「个人原因」「本人申请离职」「双方再无争议」的离职证明、离职协议、试用期不合格确认书。签之前可以拍照发给 AI 帮你看看（见下方提示词）。
2. **不要删聊天记录，不要退群。** 微信/钉钉/企业微信的聊天记录、考勤打卡、工资条、工作群，都是证据。先截图 + 导出保存。
3. **书面要一份解除通知。** 公司只口头说「不用来了」的，尽量用微信问他：「请问公司是决定解除我的劳动合同吗？从哪天开始？理由是什么？」让他**打字回复**。
4. **记住一个日期：解除之日。** 劳动仲裁时效一般是**从你知道权利被侵害之日起 1 年**（《劳动争议调解仲裁法》第二十七条）。别拖。

然后往下看，选一条适合你的路。

## 这个工具箱能帮你做什么

- 把「乱成一团」的事，整理成**仲裁员看得懂的事实时间线**
- 判断你手上有什么证据、**还缺什么证据**、缺的怎么补
- 起草**劳动仲裁申请书**初稿（不是替你定案，是帮你起个头）
- 估算你能主张多少钱、怎么算出来的
- 公司提出和解时，帮你**列清楚签之前必须核对的条款**（签不签由你决定）

## 它不会做什么（重要）

- **不替你做决定。** 要不要撤诉、要不要接受和解、要不要签字，永远是你自己的决定。AI 只列事实、风险和问题。
- **不编造法律。** 所有法律结论都会标明出处，请你到 [`06_法律依据/常用法条速查.md`](06_法律依据/常用法条速查.md) 里的官方链接自行核对。
- **不收集你的隐私。** 详见 [`隐私与安全.md`](隐私与安全.md)。**身份证号、银行卡号、合同原件照片、录音原件，不要发给任何 AI，也不要提交到本仓库。**
- **不保证结果。** 这不是法律意见，也不构成委托代理关系。详见 [`免责声明.md`](免责声明.md)。

## 拿走一份离线包

点仓库右上角 **Code → Download ZIP** 下载。

**解压后双击 `index.html`**，就能在电脑上离线用（提示词一键复制），
**不需要联网、不需要装任何软件**。

### 📱 只用手机怎么办（重要）

**不用下载，直接在浏览器里看就行：**

- 手机浏览器打开仓库地址 → 点进需要的文件 → 长按文字选中复制。
- 或者：**点「Code → Download ZIP」下载后，用手机自带的「文件管理」App
  长按压缩包 → 解压 → 找到 `index.html` → 用浏览器打开。**
  （安卓手机大多自带解压功能；iPhone 用「文件」App 长按压缩包即可解压。）

**看不懂 `.md` 文件？** 那是纯文字文件，用「WPS」或记事本就能打开。
如果你在手机上看到一堆 `#` 和 `|` 符号，那是排版符号，不影响阅读 ——
**直接看文字内容就行**，或者改用 `04_模板/` 里那份**纯文本版申请书模板**
（没有这些符号，手机填起来方便）。

**嫌麻烦就这样：** 手机上只需要看懂三样东西 ——
[`01_先做这6件事/被辞退后72小时清单.md`](01_先做这6件事/被辞退后72小时清单.md)、
[`02_AI引导工作流/从这里复制提示词.md`](02_AI引导工作流/从这里复制提示词.md)、
[`04_模板/仲裁申请书模板_纯文本版.md`](04_模板/仲裁申请书模板_纯文本版.md)。
其余的等需要时再看。
