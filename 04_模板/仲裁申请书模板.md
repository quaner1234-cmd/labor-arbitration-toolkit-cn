# 模板：劳动仲裁申请书

> **用法**：复制下面全部内容到 Word / WPS / 记事本，把 `【】` 里的东西替换成你的情况。
> **删掉所有 `【】` 和提示说明**，再把法条条号到官方数据库核对一遍。
> 这是一份**骨架**，不是可以直接提交的版本。

---

```
劳动人事争议仲裁申请书

一、当事人

申请人：【姓名】，【性别】，【民族】，【出生年月日】出生，
身份证号码：【身份证号】，
住址：【身份证地址或现住址】，
联系电话：【手机号】。

被申请人：【公司全称，必须与营业执照/企业信用信息公示系统一致】，
统一社会信用代码：【18位代码】，
住所地：【公司登记住所地】，
法定代表人：【姓名】，联系电话：【公司电话，有就写】。


二、仲裁请求

1. 裁决被申请人支付违法解除劳动合同赔偿金人民币【金额】元
   （按【月平均工资】元/月 × 【折算月数】个月 × 2 倍计算；
    如解除前十二个月平均应得工资高于【月平均工资】元，按实际平均工资核算增加）；

2. 裁决被申请人支付未休带薪年休假工资报酬人民币【金额】元
   （按【天数】天 × 【月平均工资】元 ÷ 21.75 天 × 200% 计算；
    如依法核定的前12个月月平均工资高于【月平均工资】元，按实际基数核算）；

3. 裁决被申请人支付【未结工资 / 加班费 / 提成 / 奖金】：【写清楚项目和金额，
   以及计算依据】。相关结算、台账资料由被申请人掌握，请依法责令其提供并据实核算；

4. 裁决被申请人依法出具《解除劳动合同证明》，写明劳动合同期限、解除日期、
   工作岗位、在本单位工作年限；不得记载"申请离职""双方已无纠纷"等与事实不符内容；
   并在十五日内依法办理档案和社会保险关系转移手续；如已办理社会保险减员，
   申报的减员原因应与实际解除情况一致；如存在与实际解除事实不符的登记，
   请依法予以更正。

（提示：不需要的请求删掉；需要增加的请求按同样格式补在后面。
  补缴社保一般不属于仲裁受案范围，不要写成仲裁请求。）


三、事实与理由

（一）劳动关系建立与一次试用期

申请人于【年月】入职被申请人处，双方签订书面劳动合同，
第一份合同期限为【起】至【止】，约定试用期【起】至【止】，月工资【金额】元；
第二份合同期限为【起】至【止】，约定月工资【金额】元。
此后劳动关系持续存续，直至【年月日】被申请人单方解除。
根据《中华人民共和国劳动合同法》第十九条，同一用人单位与同一劳动者
只能约定一次试用期。（见证据【X】）

（二）【岗位变动 / 调岗情况，如果有的话】

【年月日】，被申请人出具《【文件名称】》，将申请人岗位由【原岗位】
调整为【新岗位】。该次变动属于同一用人单位内部岗位调整，
并非重新建立劳动关系，亦不产生新的试用期。（见证据【X】）

（提示：如果公司发过多份关于试用期/转正的文件，且说法互相矛盾，
  在这里如实列出，注明各自日期和内容。这往往是很有力的部分。）

（三）被申请人解除劳动合同的情况

【年月日】，被申请人【口头通知 / 出具《XXX通知》】，以【公司给的理由】
为由，决定自【年月日】起解除劳动合同。申请人从未提交辞职申请。（见证据【X】）

申请人认为，上述解除构成违法解除，理由如下：【用 2-4 句话写清逻辑链条，
每一句都要能对应到证据。例如：
  第一份劳动合同已约定试用期并届满，此后劳动关系持续；
  根据第十九条，只能约定一次试用期；
  被申请人再次以"试用期不合格"并依据第三十九条第一项解除，
  该条适用前提不存在。】
依照《劳动合同法》第四十八条、第八十七条，应支付赔偿金。

（四）未休年休假

【写清楚：连续工作满12个月从哪天开始、每年应休几天、
  当年怎么折算、合计几天、公司有没有安排休】。（见证据【X】）

（五）【未结工资 / 提成 / 离职证明，按你的情况增删】

【写清楚项目和依据。提成类如果结算条件由公司掌握，
  明确写"相关资料由被申请人掌握，请依法责令其提供并据实核算"】。
（见证据【X】）


四、法律依据

1. 《中华人民共和国劳动合同法》第十九条（只能约定一次试用期）；
2. 《中华人民共和国劳动合同法》第三十九条第一项、第四十八条、第八十七条；
3. 《中华人民共和国劳动合同法》第四十七条、第五十条；
4. 《中华人民共和国劳动合同法实施条例》第二十四条；
5. 《职工带薪年休假条例》第二条、第三条、第五条；
6. 《企业职工带薪年休假实施办法》第三条、第五条、第十一条、第十二条；
   （注意：不要列第十条 —— 那条是「职工本人书面提出不休」的情形，
    对你主张未休年休假工资不利，等于替对方引入抗辩）
7. 《工资支付暂行规定》第九条；
8. 《中华人民共和国劳动争议调解仲裁法》第六条、第二十一条、第二十七条、第五十三条。

（⚠️ 以上条号请逐条到 flk.npc.gov.cn 核对原文和现行有效性，
   不适用的删掉，需要补充的按同样格式加上。）


五、证据（均为复印件/打印件，原件开庭核对）

1. 身份证复印件；
2. 被申请人营业执照信息（国家企业信用信息公示系统查询打印件）；
3. 劳动合同；
4. 【按你的证据目录依次列】。

申请人保留在举证期限内依法补充提交相关证据的权利。


六、结语

综上，【一两句话概括你的核心主张】。恳请仲裁委依法支持申请人的仲裁请求。

此致
【XXX】劳动人事争议仲裁委员会
（如认为应由【XXX】劳动人事争议仲裁委员会管辖，申请人服从依法移送）

申请人（签名并按手印）：____________
年    月    日

附：
1. 本申请书一式【三】份（份数请向当地仲裁委确认）；
2. 证据材料按证据目录装订；
3. 【计算附件，如《未结算订单与提成计算表》】。
```
