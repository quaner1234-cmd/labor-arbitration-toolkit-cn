# 专项：公司第二次约定「试用期」再以不合格辞退

> **⚠️ 适用范围：只有一种情况能用这个文件。**
>
> **适用**：你入职时已经约定过一次试用期，并且**劳动关系从头到尾没断过**
> （没离职、没重新入职），后来公司又搞了一个「新试用期」
> （常见于调岗、转岗、续签之后），再以「试用期不合格」辞退你。
>
> **不适用**（请改用 [`仲裁申请书模板_纯文本版.md`](仲裁申请书模板_纯文本版.md)）：
> - 第一次试用期内被辞退（那一次试用期本身是合法的）
> - 你中间离职过、又重新入职
> - 公司给的理由不是「试用期不合格」（比如「不能胜任」「违纪」「裁员」）
> - 公司根本没说理由，或者只是口头让你走
>
> **这个文件只讲「事实与理由」这一段怎么写，不是整份申请书。**
> 整份申请书还是用通用模板，把这里的内容填进「三、事实与理由」。

---

## 一、先判断：你到底是不是这种情况

逐条打勾，**必须全部满足**才适用：

- [ ] 入职时，劳动合同里**明确写过**试用期（起止日期）
- [ ] 那次试用期**已经结束**（过去了）
- [ ] 之后你**一直在同一家公司**，没有离职重进
- [ ] 后来公司又弄出一个「试用期」（调岗后、续签后、或者发通知延长）
- [ ] 公司辞退你时援引的是「**试用期不符合录用条件**」或类似说法

**有任何一条不满足 → 不适用这个专项。** 用通用模板。

---

## 二、法律依据（只有一条主线）

**《中华人民共和国劳动合同法》第十九条：同一用人单位与同一劳动者
只能约定一次试用期。**
（**请到 flk.npc.gov.cn 核对原文** —— 这是整个论证的核心，务必自己核）

**逻辑链条（四步，缺一不可）：**

```
① 入职时已经约定过一次试用期，且已经结束
        ↓
② 之后劳动关系一直没中断（没离职、没重新入职）
        ↓
③ 所以第二次约定的「试用期」违法（违反第十九条）
        ↓
④ 公司援引第三十九条第一项「试用期不合格」解除 →
   这一条的适用前提（存在合法有效的试用期）不存在 → 违法解除
```

**为什么只打这一条？**
主线成立就够了。多开战线（比如「公司没培训」「考核不公平」）
每一条都要单独举证，反而把主线淹没，还给对方更多反驳点。

---

## 三、「事实与理由」怎么写（可直接改的骨架）

把下面的【】换成你的情况。每一句都要能对应到证据。

```
（一）劳动关系建立与第一次试用期

申请人于【年月】入职被申请人处，双方签订书面劳动合同，
合同期限【起】至【止】，约定试用期【起】至【止】，月工资【金额】元。
该试用期已于【年月日】届满。此后双方劳动关系持续存续，
申请人未离职、未重新入职，直至【年月日】被申请人单方解除。
（见证据【X：劳动合同】）

（二）【公司第二次设定试用期的情况】

【年月日】，被申请人【做了什么：出具调岗通知 / 续签合同 /
  发出延长试用期通知】，其中约定（或称）试用期【起】至【止】。
该次变动发生在劳动关系持续存续期间，并非重新建立劳动关系。
（见证据【X】）

（三）被申请人以「试用期不合格」解除

【年月日】，被申请人出具《【解除通知名称】》，以
「试用期不符合录用条件」为由，决定自【年月日】起解除劳动合同。
申请人从未提交辞职申请。（见证据【X：解除通知】）

申请人认为，上述解除构成违法解除，理由如下：
入职时双方已约定试用期并已届满，此后劳动关系持续存续，
申请人从未离职或重新入职。根据《中华人民共和国劳动合同法》
第十九条，同一用人单位与同一劳动者只能约定一次试用期。
被申请人在劳动关系存续期间再次设定试用期，并以「试用期不合格」
依据该法第三十九条第一项解除劳动合同，
该条的适用前提（存在合法有效的试用期）并不存在。
依照该法第四十八条、第八十七条，应支付赔偿金。
（见证据【X】）
```

## 四、很有用的一招：列矛盾点

**公司自己出的几份文件对试用期说法不一致**，摆出来特别有效。
不需要你论证，仲裁员自己会看到。

| 文件 | 公司对试用期的说法 |
|---|---|
| 劳动合同（入职时） | 【写了什么】 |
| 【调岗通知】（【日期】） | 【写了什么 / 有没有提试用期】 |
| 【延长试用期通知】（【日期】） | 【写了什么】 |
| 【解除通知】（【日期】） | 【写了什么】 |

**所以：公司给你的每一份纸都要留好。** 包括你觉得「不重要」的那些。

---

## 五、公司可能怎么反驳，你该怎么接

| 公司可能说 | 这个说法成立需要什么 | 你怎么回应 |
|---|---|---|
| 「我们签了转岗协议，里面约定了新试用期」 | 得拿出这份协议 | 即使有，也违反第十九条（只能一次）；你没见过的，可要求公司提供 |
| 「你考核确实不合格」 | 得有事先明确的录用条件 + 考核记录 | 没有合法试用期，第三十九条第一项就用不了 |
| 「是协商一致解除 / 你自己申请离职」 | 得有你签字的申请 | 你没签过；如果离职证明写「申请离职」而实际没有，这本身就是矛盾点 |
| 「第一次试用期没过，延长而已」 | 得证明第一次试用期还没结束 | 看第一次合同约定的截止日 |

**⚠️ 上表只是帮你预判，不替你决定怎么应对。**

---

## 六、你还需要哪些证据

| 必须有 | 有了更好 |
|---|---|
| 劳动合同（**证明第一次试用期**） | 转正通知 / 转正述职记录 |
| 解除通知（**证明公司援引了试用期不合格**） | 公司的录用条件、考核标准（**公司拿不出来，它的理由就很难成立**） |
| 第二次设定试用期的文件 | 各版本离职证明（**多版本不一致全部保留**） |
| 工资流水（算赔偿金额数） | 与人事的聊天记录 |

**公司掌握但你没有的**，可以在仲裁中请求仲裁庭责令公司提供
（《劳动争议调解仲裁法》第六条，**请核对原文**）：
考勤台账、考核表、书面录用条件、所谓「转岗协议」全文。

---

## 七、一个真实的教训

有个案子里，公司拿出**三份**文件让劳动者签，其中一份是
「延长试用期通知」。

**签了会怎样？** 等于承认公司有权延长试用期 ——
**这会直接削弱你「第二次试用期违法」这个主线。**

**教训：签字前不要只看「要不要签」，要看「签的字承认了什么事实」。**
不确定的文件，可以先说「我考虑一下」，拍照带走。
