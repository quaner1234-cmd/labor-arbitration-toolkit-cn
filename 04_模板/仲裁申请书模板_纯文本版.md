# 模板：仲裁申请书（纯文本版 · 手机和 WPS 直接能用）

> **这一份是给不懂 Markdown 的人用的。**
> 复制下面全部文字 → 粘到 WPS / Word / 手机备忘录 → 按下面规则改 → 删掉所有【】和提示说明。

## 📌 【】怎么处理（重要，先看这个）

模板里的 `【】` 有**两种**，处理方式不同：

| 情况 | 怎么做 | 例子 |
|---|---|---|
| **里面是提示，要换成你的真实信息** | **连【】一起换成内容** | `【姓名】` → 改成 `王小明` |
| **整段是说明/选项，不是你要写的** | **整段删掉** | `【按你的情况增删】` → 删掉 |
| **拿不准要不要写** | 先删掉，需要时再加回来 | — |

**判断方法**：如果 `【】` 里写的是**你自己才知道的事**（姓名、日期、金额、公司名），
就是要替换；如果写的是**给你看的提示**（「如果有的话」「按你的情况增删」「怎么查」），
就是删掉。

**改完自检**：在 WPS 里搜一下 `【`，**搜不到任何一个才算改完**。
>
> **⚠️ 这是一份「通用骨架」，不是现成答案。**
> 里面的示例（比如岗位、日期、理由）都是**占位符**，
> **不要照抄**。哪些事实要写、怎么写，取决于你自己的情况。

```
劳动人事争议仲裁申请书

一、当事人

申请人：【姓名】，【性别】，【民族】，【出生年月日】出生，
身份证号码：【自己填，不要发给AI】，
住址：【身份证地址或现住址】，
联系电话：【手机号】。

被申请人：【公司全称，必须和营业执照一字不差】，
统一社会信用代码：【18位代码，去 www.gsxt.gov.cn 查】，
住所地：【公司登记的住所地】，
法定代表人：【姓名】，联系电话：【公司电话，有就写】。

【怎么查公司信息】
打开 www.gsxt.gov.cn（国家企业信用信息公示系统），搜公司名字，
点进去就能看到：全称、18位代码、住所地、法定代表人。免费。
必须抄登记全称，不能写平时叫的简称，不能写错一个字。


二、仲裁请求

1. 裁决被申请人支付【写清楚要什么钱】人民币【金额】元
   （按【基数】×【月数/天数】×【倍数】计算，写清楚每个数从哪来的；
    如实际平均工资高于【基数】，按实际核算增加）；

2. 裁决被申请人支付【第二项请求，如果有的话】；

3. 裁决被申请人依法出具《解除劳动合同证明》，写明劳动合同期限、
   解除日期、工作岗位、在本单位工作年限；并在十五日内依法办理
   档案和社会保险关系转移手续；如已办理社会保险减员，申报的减员
   原因应与实际解除情况一致。

【填请求的三条】
1. 一条只讲一件事
2. 写出计算过程，让仲裁员一眼看懂
3. 没有的请求就删掉，不要硬凑
   注意：补缴社保一般不写在这里（走社保经办机构或劳动监察）


三、事实与理由

（一）劳动关系建立
申请人于【年月】入职被申请人处，岗位是【岗位】，月工资【金额】元。
双方签订书面劳动合同，期限【起】至【止】。
（见证据【X】）

（二）【第二段：写公司做了什么，比如调岗、发通知】
【年月日】，被申请人【做了什么，出具了什么文件】，内容是【摘要】。
（见证据【X】）

（三）解除的情况
【年月日】，被申请人以【公司给的理由】为由，
决定自【年月日】起解除劳动合同。申请人从未提交辞职申请。
（见证据【X】）

申请人认为上述解除【是否合法，你自己的判断，用2-4句话写清逻辑，
  每一句都要能对应到证据】。

（四）【其他请求对应的事实，比如未休年假、未结工资，按你的情况增删】
（见证据【X】）


四、法律依据

1. 《中华人民共和国劳动合同法》第【 】条（一句话说明这条支持我什么）；
2. 《中华人民共和国劳动争议调解仲裁法》第【 】条；
3. 【按你的情况增删】

【⚠️ 重要】上面每一条都要你自己去 flk.npc.gov.cn 核对原文。
AI 写的条号可能是错的。写错条号比不写更糟。
不适用的删掉，需要补的按同样格式加上。


五、证据（均为复印件/打印件，原件开庭核对）

1. 身份证复印件；
2. 被申请人企业信用信息公示打印件；
3. 劳动合同；
4. 【按你的证据目录依次列，见 证据目录模板.md】

申请人保留在举证期限内依法补充提交相关证据的权利。


六、结语

综上，【一两句话概括你的核心主张】。
恳请仲裁委依法支持申请人的仲裁请求。

此致
【XXX】劳动人事争议仲裁委员会
（如认为应由【XXX】劳动人事争议仲裁委员会管辖，申请人服从依法移送）

申请人（签名并按手印）：____________
年    月    日

附：
1. 本申请书一式【三】份（份数请先打电话向当地仲裁委确认）；
2. 证据材料按证据目录装订。
```

## 填完以后，逐条自查

- [ ] 所有【】都替换了吗？提示文字都删了吗？
- [ ] **法条条号自己核过了吗？**（去 flk.npc.gov.cn）
- [ ] 每个数字重新算一遍了吗？
- [ ] 公司全称和 18 位代码核准了吗？
- [ ] 有没有情绪化的话？（「公司欺负人」这类，有就删）
- [ ] 有没有写没有证据支撑的话？（有就删或补证据）
- [ ] 份数、地址**打电话确认**了吗？（仲裁委会搬家）
- [ ] 原件带着吗？
