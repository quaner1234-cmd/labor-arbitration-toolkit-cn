# 模板：案件摘要卡片（跨对话用）

> **解决什么问题**：AI 聊天换个新对话，前面说过的内容就全没了，
> 你要把所有情况再讲一遍。
>
> **怎么用**：每走完一段，让 AI 填一张这个卡片，你**复制保存到手机备忘录**。
> 下次开新对话时，把**这张卡片 + 规则兜底块 + 下一段提示词**一起粘贴给 AI，
> 它就能接着上次的进度继续，你不用重新回答全部问题。

---

## 三步走

```
第 1 段结束 → AI 给你「摘要卡片 v1」→ 你复制保存到备忘录
                    ↓
        新开对话（比如手机换电脑、聊太久了）
                    ↓
  粘贴：摘要卡片 v1 + 规则兜底块 + 第 2 段提示词
                    ↓
        AI 说「我看到了你的情况，我们继续」→ 直接往下走
```

**⚠️ 每次开新对话，摘要卡片和规则兜底块都要一起发。**
只发卡片不发兜底块，AI 就不知道要区分【事实】/【推断】/【待核实】。

---

## 卡片模板（复制这个给 AI，让它填）

````text
请帮我填一张「案件摘要卡片」，我要保存下来下次继续用。
格式如下，每一项都要填；我不知道的就写「待核实」，不要留空、不要替我编。

【案件摘要卡片 v1】

一、我是谁、告谁
- 我在的城市：
- 公司全称（或还不清楚）：
- 我的岗位：
- 入职日期：
- 解除日期：
- 月工资（合同写的 / 实际到手，分开写）：

二、发生了什么（按时间，每条后面写「有材料 / 没材料」）
1. 【日期】……（有材料：劳动合同）
2. 【日期】……（有材料：无）
3. 【日期】……（有材料：解除通知）

三、公司给的解除理由
- 公司说的是：
- 公司给了什么书面文件：
- 这些文件之间有没有矛盾：

四、我手上的材料（有就写，没有就不写）
- 劳动合同：有 / 无
- 解除通知：有 / 无
- 离职证明：有 / 无
- 聊天记录：有 / 无
- 工资流水：有 / 无
- 社保记录：有 / 无
- 其他：

五、我还缺什么（AI 填）
- 缺什么 / 去哪拿 / 谁手里有

六、我想主张什么（我自己决定的，AI 不许替我填）
- 赔偿金：要 / 不要 / 还没决定
- 未结工资：要 / 不要 / 还没决定
- 未休年假：要 / 不要 / 还没决定
- 出具离职证明：要 / 不要 / 还没决定

七、【事实】/【推断】/【待核实】清单（AI 填）
- 事实：……
- 推断：……（写明推测依据）
- 待核实：……

八、下一步
- 我该走第【 】段
````

---

## 下次开新对话时怎么发

**把这三样按顺序粘在一起，一次发过去：**

````text
【我上次做到哪里了】
（粘贴你保存的摘要卡片）

【规则，请继续遵守】
（粘贴 02_AI引导工作流/00_规则兜底块 里的内容）
1. 严格区分【事实】/【推断】/【待核实】
2. 不许编造我没说过的事实、证据、法条条号
3. 不许替我做决定
4. 我说不知道就记待核实
5. 用大白话
6. 一次只问一个

【现在继续做第 X 段】
（粘贴第 X 段提示词全文）
````

---

## 为什么这样能行

AI 是「看了你发的文字才知道你是谁」。你把摘要发过去，
它就知道你入职哪天、被谁辞退、手上有什么材料 ——
**这些信息不用再讲第二遍。**

**比重新回答全部问题省多少事？**
第 1 段大约要问 8-10 个问题。有摘要的话，一步就过去了。

---

## 小提示

- 卡片**每走完一段更新一次**（v1 → v2 → v3），别用旧的；
- 卡片里**不要写身份证号、银行卡号** —— 你自己看得懂就行；
- 保存到手机备忘录，或者微信「文件传输助手」；
- 如果懒得填完整卡片，**至少要保存这 5 项**：
  入职日期 / 解除日期 / 公司说的理由 / 手上有什么材料 / 走到第几段了。
