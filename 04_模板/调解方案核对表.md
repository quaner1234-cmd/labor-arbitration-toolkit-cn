# 模板：调解方案核对表

> **公司提出和解时，用这张表逐条过。**
> 本表**不帮你决定签不签** —— 只帮你看清每一条在说什么。
> 决定权永远在你。

---

## 第 0 步：先问自己三个问题

1. 我可以**现在不签**吗？（答案：可以。说「我考虑一下」，把文件带走。）
2. 这份文件我**每一条都看懂**了吗？（有不懂的，先别签。）
3. 我有没有找**真人**看过？（可以打 **12348** 免费咨询。）

---

## 第 1 步：翻译

把每一条法律/半法律的表述，翻译成大白话。

| 原文 | 人话：这句话实际上说什么 | 签了会怎样 | 风险 |
|---|---|---|---|
| 【粘贴原文】 | | | 🔴 / 🟡 / 🟢 |
| 【粘贴原文】 | | | 🔴 / 🟡 / 🟢 |

**风险等级：**
- 🔴 **高危**：可能让我丧失重要权利
- 🟡 **需确认**：表述含糊、履行方式不明
- 🟢 **正常**

---

## 第 2 步：高危措辞扫描

文件里有没有下面这些？有就停下来想一遍。

- [ ] 「本人因**个人原因**申请离职」「自愿离职」🔴
- [ ] 「**双方再无争议**」「无其他纠葛」「放弃一切权利」🔴
- [ ] 「**试用期考核不合格**」「不符合录用条件」（如果你不认可）🔴
- [ ] 「**双方协商一致**解除」（如果实际是被单方辞退）🔴
- [ ] 付款**没写金额** 🔴
- [ ] 付款**没写时间**（「近期」「尽快」）🔴
- [ ] 付款**没写方式**（哪个账户）🔴
- [ ] 要求**先撤诉、后付款** 🔴🔴（最高危）
- [ ] 要求放弃**社保、公积金**主张 🔴
- [ ] 有**空白待填**的地方 🔴🔴（**绝对不签**）
- [ ] 要求**倒签**历史文件（补签以前日期的试用期通知、考核表等）🔴

---

## 第 3 步：签字前核对清单

**钱：**
- [ ] 金额写清楚了吗？数字 + 币种？
- [ ] **税前还是税后**？
- [ ] 付款时间具体到**哪一天**？（不能写「尽快」「近期」）
- [ ] 付款方式写了吗？（银行转账到**哪个账户**？开户行？）
- [ ] **逾期不付**怎么办？有没有违约责任？

**⚠️ 有没有漏项**（这些最常被一次性终结条款吞掉）：
- [ ] **最后一个月的正常工资**结清了吗？（很多协议只写补偿金，漏掉未发工资，
      然后被「一次性终结」覆盖）
- [ ] **未结提成/加班费**都算进去了吗？
- [ ] 提成比例是按多少算的？和我原来主张的一致吗？

**手续：**
- [ ] **离职证明**：怎么出？什么时候出？**写什么内容**？（写明解除原因了吗？）
- [ ] **社保减员原因**：写成什么？**谁来改**？什么时候改？
- [ ] **失业金配合**：是否写明单位配合办理？
      ⚠️ 注意：协议只能写单位的**配合义务**，没人能保证失业金一定办下来
- [ ] 档案和社保关系转移手续：写了吗？

**程序：**
- [ ] 是否要求我**撤回仲裁**？如果是 —— **先付钱还是先撤诉**？🔴
- [ ] 有没有「放弃权利」的表述？**我要放弃的到底是什么**？列出来
- [ ] 有没有要求我**倒签**历史文件？（比如补签以前的试用期通知）🔴
- [ ] 一式几份？**我能拿到一份原件吗**？
- [ ] 对方签字了吗？盖章了吗？签字的人有授权吗？
- [ ] 有没有空白没填的地方？

---

## 第 4 步：区分「行为义务」和「结果保证」

这一条非常重要，很多人在这里吃亏。

| 可以写进协议（行为义务） | 不能指望（结果） |
|---|---|
| 「被申请人应于签署后 X 个工作日内**向社保经办机构申请更正**减员原因，并**提交**所需真实材料」 | 「保证 X 天内社保系统一定改好」 |
| 「**配合**申请人办理失业保险金申领及异议重新审核」 | 「保证失业金一定到账」 |
| 「于 X 年 X 月 X 日前**支付**人民币 X 元至指定账户」 | （付款是行为，但到账要有流水凭证） |

**为什么？** 公司能控制的是「去申请、去提交、去配合」，
控制不了经办机构审核多久、批不批。
**写成「保证办好」的条款，对方做不到时你反而难以追责；
写成明确的行为义务 + 期限，对方没做就是违约。**

---

## 第 5 步：签字之后要拿什么

- [ ] **协议原件**（我自己一份，不是复印件）
- [ ] **付款流水凭证**（钱到账才算数，不是签了字就算数）
- [ ] **解除证明原件**
- [ ] **社保更正申请的回执/凭证**
- [ ] 记下：签署日期、在场的人、有没有现场要求签别的文件

---

## 第 6 步：签完还要跟的事

| 事项 | 怎么验证 |
|---|---|
| 钱到账了吗 | 查银行流水，**不看对方说没说，看账上有没有** |
| 离职证明拿到了吗 | 看内容是否与事实相符 |
| 社保减员原因改了吗 | **打 12333 或到窗口查系统**，不靠对方口头 |
| 失业金能办了吗 | 问经办机构，可能仍需补充材料 |
| 仲裁怎么处理 | **问仲裁委**：撤诉还是出调解书？不要自己默认 |

**⚠️ 关键：**
- **签了调解协议 ≠ 仲裁自动结束。** 要向仲裁委确认程序怎么处理；
- 在仲裁委主持下达成的**调解书**，通常可以直接申请强制执行；
  **私下签的协议如果对方不履行，你还得再走一遍诉讼。**
  所以能走仲裁调解书就走调解书。
- 原协议里如果写着「携第 X 份到区仲裁院置换调解书」，
  **置换出来的到底是什么文书、有没有强制执行力，要向仲裁机构问清楚**，
  不要默认等同于生效调解书。

## 最后三句话

1. **你可以说「我考虑一下」，然后带着文件回家。**
2. **没有人能强迫你在看不懂的协议上签字。**
3. **在弄清楚之前，可以不签。**
